
# pruebaFirebase

Primer commit ReadMe

Este proyecto es una app Ionic/Angular con Capacitor.

## Comandos útiles

- Instalar dependencias:
	```
	npm install
	```
- Servir en modo desarrollo:
	```
	ionic serve
	```
- Generar iconos y splash:
	```
	npx @capacitor/assets generate
	npx cap sync
	```
- Abrir en Android Studio:
	```
	npx cap open android
	```

## Estructura
- `NEW2/` contiene el código fuente de la app.
- `resources/` contiene los iconos y splash.
